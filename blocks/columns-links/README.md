# columns-links

Custom **columns** block. 

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row, one cell of content.

## Supported variations

- Default: inner-page link list (48px arrow, tight section spacing), e.g. employers "Getting started".
- `compact`: homepage "I want to..." list (32x23 arrow, narrower stacked columns, roomier section
  spacing). Added automatically by `decorate()` on the page that contains a `search-banner` block.

## Universal Editor fields

- Content fields derived from the block's decorate contract.
