# quote-bordered

Custom **quote** block. Purpose: body-size statement quote set off with a grey left rule.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: row 1 is the quotation (one or more paragraphs, a single Quotation richtext field); row 2 is the optional attribution (plain text name and role, Attribution field; the leading em dash is added by CSS).

## Supported variations

No variations.

## Universal Editor fields

- Content fields derived from the block's decorate contract.
